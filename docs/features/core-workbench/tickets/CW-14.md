## 범위 밖과 중단 조건

상한으로 실행을 종료하거나 손실된 log를 복원 완료로 표시하거나 metadata 오류를 무시하고 새 자동 run을 시작하면 중단한다.

Phase 2·내부 외부 multiplexer·무단 commit/push/merge·미승인 동작 확대는 범위 밖이다. Gate item은 이 ticket 또는 전이적 선행 산출물만 사용한다. 후속 통합의 책임을 초기 통과 조건으로 요구하지 않는다.
