## 제공할 동작

사용자 위임 승인·진행 지시를 TaskSpec revision과 연결하고 run/cancel 이력·세션 공통 설정을 durable metadata에 보존한다. CW-08이 사용할 Task/revision/run 연계 논리 메시지·전달 상태 기록 경계를 제공한다. 새 자동 실행은 승인 범위와 저장 성공이 확인된 때만 허용한다.

## 계약과 선행 산출물

Task ID는 revision/commit 변경으로 재설정하지 않는다. 실행 중 명세 변경은 새 revision을 다음 run에 적용한다. 즉시 중단·권한 철회는 현재 run에 적용한다. 세션 공통 설정은 각 Task의 이후 판단에 적용하고 변경 전후 설정과 사용한 재시도 횟수의 연결을 보존한다. 안정된 `message_id`와 관련 Task/revision/run·전달 상태의 영속 기록 경계를 CW-08에 제공한다. Storage schema 변경은 이 ticket이 소유한다. API 복귀와 확인된 OMP 처리는 서로 다른 기록이다. Shell 전송/수락/시작/종료와 takeover 요청/확인도 기존 run을 덮어쓰지 않고 연결할 port를 제공한다.

선행 산출물·통합 경계는 PLAN의 이 ticket 및 `dependency_artifacts`를 따른다.

## 검증

승인 전 실행 거절, 승인+진행 후 시작, revision 불변성, 취소 뒤 이전 revision 재실행 금지, metadata write failure에서 새 실행 보류를 검증한다. 동일 `message_id`의 논리 메시지와 별도 전달 상태 기록이 Task/revision/run에 연결되는지 확인한다. 실행 중 세션 설정을 바꿔도 현재 run을 종료하거나 사용한 재시도 횟수를 초기화하지 않으며 다음 판단에 새 설정을 연결하는지 확인한다. 독립 test_designer가 누락된 전이 사례를 작성하고 reviewer가 불변 기록을 점검한다.

## 범위 밖과 중단 조건

승인 범위가 표현되지 않거나 metadata 쓰기 실패를 무시해야 실행 가능한 경우 중단한다.

Phase 2·내부 외부 multiplexer·무단 commit/push/merge·미승인 동작 확대는 범위 밖이다. Gate item은 이 ticket 또는 전이적 선행 산출물만 사용한다. 후속 통합의 책임을 초기 통과 조건으로 요구하지 않는다.
