## 계약과 선행 산출물

## 검증

실제 Bash와 sh에서 같은 PID/cwd/export와 검증한 conda·venv가 유지되는지 확인한다. 수동 인수 직전 아직 미전송인 요청은 보내지 않고, 이미 전달된 명령은 실행/종료/불명을 그대로 표시한다. 실행 중 foreground stdin을 인수 후 직접 조작하며 실험 종료나 prompt 복귀를 인수 확인의 전제로 요구하지 않는다. 대상 불명일 때 입력을 보류한다. 수동 작업 뒤 직접 wb-handoff→control 대기와 비호환 hook/trap 보류를 확인하고 인수/상태 대조 뒤 오래된 요청을 replay하지 않는다. 최초 승인+진행은 별도 AUTO ON을 요구하지 않으며 일시정지 중 handoff는 자동 재개가 아니다. Startup shell 선택·둘 다 없을 때 안내·app 환경 분리도 검증한다.

## 범위 밖과 중단 조건

Shell identity나 lifecycle 증거가 불명확할 때 자동 실행·종료를 추정해야 하면 중단한다. G2에서 검증하지 않은 shell은 지원 완료로 표시하지 않는다.

Phase 2·내부 외부 multiplexer·무단 commit/push/merge·미승인 동작 확대는 범위 밖이다. Gate item은 이 ticket 또는 전이적 선행 산출물만 사용한다. 후속 통합의 책임을 초기 통과 조건으로 요구하지 않는다.
