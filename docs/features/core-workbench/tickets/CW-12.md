## 제공할 동작

일시정지 요청 즉시 새 자동 지시를 보류하고 manager OMP 진행 중 turn 중단을 요청한다. 요청·확인·불명 도구 결과와 마지막 작업·확인된 파일 변경·실행 중 프로세스를 표시한다. 새 자동 manager/worker 모델 작업과 periodic review는 시작하지 않고 로그·프로세스 수집과 기존 실험은 유지한다. 명시적 재개 뒤 실제 상태·승인 범위를 대조하고 중단 명령·대기 요청은 replay하지 않는다.

## 검증

실제 manager OMP turn 진행 중 pause를 요청하고 즉시 새 자동 지시 보류/abort 요청, turn 종료 관측, tool 결과 불명과 확인된 파일 변경을 실제 CW-06 UI에 구분해 표시한다. 새 자동 manager/worker 모델 작업·pending 점검은 멈추고 host 실험·로그/process 수집은 유지한다. 수동 agent 지시/조사/rollback은 자동화를 켜지 않으며 terminal 인수와 자동화 pause도 별개다. 명시적 재개에서 파일·tool·terminal process·task·현재 승인 범위를 대조하고 old command/request는 replay하지 않는다. 취소 뒤 기록·결과 파일을 보존한다. A 완료 대기/B 별도 차단 시험은 사용하지 않는다.

## 범위 밖과 중단 조건

중단 요청만으로 turn·도구 완료나 rollback을 주장하거나, 일시정지 중 새 자동 모델 작업을 시작하거나, 재개 시 중단 명령·대기 요청을 자동 replay하면 중단한다.

Phase 2·내부 외부 multiplexer·무단 commit/push/merge·미승인 동작 확대는 범위 밖이다. Gate item은 이 ticket 또는 전이적 선행 산출물만 사용한다. 후속 통합의 책임을 초기 통과 조건으로 요구하지 않는다.

## 산출물 인계
