# CW-12: 자동화 일시정지와 진행 중 도구 작업

명세: [SPEC.md](../SPEC.md) s2.2. Scheduling·resource·scope의 원본: [PLAN.json](../PLAN.json) CW-12 항목. Live 상태와 작업 배정은 Root의 별도 workflow state에서 관리한다.

## 제공할 동작

자동화 일시정지 요청 즉시 새 자동 지시를 보류하고 manager OMP의 진행 중 turn 중단을 요청한다. 요청·실제 중단 확인·도구 결과 불명을 구분하고 마지막 작업·확인된 파일 변경·실행 중 프로세스를 표시한다. 일시정지 중 manager·worker의 새 자동 모델 작업과 1분 worker 모델 점검을 시작하지 않고 로그·프로세스 수집과 기존 host 실험은 유지한다. 사용자 수동 조작은 자동 재개가 아니며, 명시적 재개와 취소를 구분한다.

## 수락 기준

- C-AC-25: 승인 범위·Task/revision/run·취소와 중단 요청·확인·불명 결과 연결. 최종 I-POLICY에서 재확인.
- C-AC-30: 일시정지 중 새 자동 모델 작업 중단·로그/프로세스 수집과 기존 실험 유지·수동 조작 독립. 최종 I-POLICY에서 재확인.
- C-AC-33: manager turn 중단 요청/확인, 불명 결과 표시, 명시적 재개 상태 대조와 replay 금지. 최종 I-POLICY에서 재확인.

## 계약과 선행 산출물

- CW-09: 영속 위임·취소·권한 상태가 통합·검증됨.
- CW-11: 일시정지 중에도 유지할 로그·프로세스 관측 경로와 중단할 모델 점검 경로가 통합·검증됨.

CW-09의 승인/취소, CW-11의 review 경계, CW-04/05에서 실증한 OMP turn 중단 요청·확인 계약을 소비한다. 일시정지는 현재 run 종료나 도구 rollback을 뜻하지 않는다. 명시적 재개 시 실제 파일·도구 결과·terminal 프로세스·작업 상태와 승인 범위를 대조한다. 중단 명령·대기 요청은 자동 재실행하지 않고, 취소는 기록·결과 파일의 자동 삭제가 아니다.

계획 write scope: `src/workbench/policy/pause_*/**`, `tests/policy/pause_*/**`, `omp_bridge/policy_*/**`. 실제 dispatch 전에 Root가 current base·소유권·resource claim을 다시 확인한다.

## 검증

실제 manager OMP turn 중 일시정지 요청, 중단 요청·확인 분리, 불명 도구 결과와 확인된 파일 변경 표시를 확인한다. 일시정지 중 새 자동 manager/worker 작업·worker 모델 점검은 보류하고 로그·프로세스 수집과 기존 host 실험은 유지한다. 사용자 직접 조사·수정·rollback·agent 수동 지시가 자동 재개를 일으키지 않는지 검증한다. 명시적 재개 후 실제 상태·승인 범위 대조, 중단 명령·대기 요청 replay 금지, 취소 시 기록·결과 파일 보존을 확인한다. 독립 test_designer/reviewer가 전이 경합을 평가한다.

공통 검증: worker quick check → 독립 test_designer 평가/필요 테스트 → 동결 후보 fresh reviewer → 필요한 수정·delta review → Root 통합 및 SPEC의 최종 check. 명령·cwd·candidate·환경·결과를 기록한다.

## 범위 밖과 중단 조건

중단 요청만으로 turn·도구 완료나 rollback을 주장하거나, 일시정지 중 새 자동 모델 작업을 시작하거나, 재개 시 중단 명령·대기 요청을 자동 replay하면 중단한다.

Phase 2·내부 외부 multiplexer·무단 commit/push/merge·미승인 제품 동작 확대는 이 ticket의 범위가 아니다.

## 산출물 인계

변경 경로와 근거를 특정한 candidate/output bundle, 실제 수행한 check와 미실행 사유, 실패·미확인 gate/acceptance, 다음 ticket이 소비할 계약 변경점을 Root에게 전달한다. Ticket 작성자가 PLAN/state/approval을 직접 바꾸지 않는다.
