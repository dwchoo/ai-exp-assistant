## 검증

실제 두 OMP·persistent host shell에서 목표→승인→worktree/run→60초 점검→완료·실패 복구, 수동 제어, detach, 저장/모델 장애를 시험한다. C-AC-19/20은 일반 terminal/tmux/herdr와 Bash·실제 sh matrix를 조작하고 기본/login shell이 zsh인 경우, Bash/sh가 둘 다 없는 경우의 안내를 검증한다. 누락된 service/capability는 pending으로 남긴다. test_designer와 fresh reviewer 및 최종 checks를 실행한다.

공통 검증: worker quick check → 독립 test_designer 평가/필요 테스트 → 동결 후보 fresh reviewer → 필요한 수정·delta review → Root 통합 및 SPEC의 최종 check. 명령·cwd·candidate·환경·결과를 기록한다.

## 범위 밖과 중단 조건

필수 gate나 acceptance가 실패/미확인인데 done_verified로 닫지 않는다. 실제로 실행하지 않은 외부 조합은 통과로 기재하지 않는다.

Phase 2·내부 외부 multiplexer·무단 commit/push/merge·미승인 제품 동작 확대는 이 ticket의 범위가 아니다.
